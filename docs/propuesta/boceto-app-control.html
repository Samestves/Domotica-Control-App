Boceto de concepto · Rev. A

Una app para controlar la casa, el carro y lo que conecten.

Este plano traduce los requisitos del equipo en pantallas. Puedes tocar los botones, mover el joystick y girar el dial: cada control muestra el mensaje que la app enviaría a la placa.

A‑01

Un teléfono, tres placas conectadas a la vez

La app guarda cada placa con su tipo de conexión y su perfil. Los mensajes viajan en los dos sentidos: órdenes hacia la placa y lecturas de sensores y alarmas de vuelta al teléfono.

Pantalla 3 · interactiva

Panel «Auto Robot»

  1. 1Dirección izquierda y derechaArrastra el joystick. Al soltarlo vuelve al centro y el carro se detiene.
  2. 2Acelerador y reversaArrastra la barra hacia arriba para acelerar. «Reversa» invierte el sentido de los motores.
  3. 3Giro de 360°Gira el dial para mover un servo de rotación continua, por ejemplo una torreta o una cámara.
  4. 4Datos de vueltaEl sensor ultrasónico envía la distancia al obstáculo. Debajo de 20 cm, la app avisa.
A‑04

Catálogo de controles

Los paneles se arman con estas piezas. Cada una se conecta a un pin virtual, igual que en Blynk, pero el panel se puede diseñar libremente.

Switch

Enciende o apaga un relé, un LED o un motor.

V1 → 0 | 1

Botón

Pulsación corta o mantenida. Sirve para el timbre o la bocina.

V5 → 1 al pulsar

Slider

Valor continuo: ángulo de un servo, brillo o velocidad.

V4 → 0 … 180

Dial 360°

Giro completo para servos de rotación continua o torretas.

V21 → 0 … 359

Joystick

Dirección en dos ejes para conducir carros y robots.

V20 → x,y (−100 … 100)

Alarma

Se arma desde la app. La placa avisa si un sensor se activa.

V7 ← DISPARO

Mensajes

Consola para enviar texto a la placa y leer lo que responde.

V6 ↔ texto

Lectura y gráfica

Muestra el valor de un sensor y su historial reciente.

V10 ← 24,1
A‑05

Un idioma común entre la app y las placas

Todos los mensajes tienen la misma forma: pin virtual, dos puntos y valor. Así, la placa entiende igual un mensaje que llega por Bluetooth o por Wi‑Fi. Esto también resuelve el «procesamiento de datos» que pide el requisito.

Mensajes

# app → placa
V1:1          enciende la luz de la sala
V3:90         servo de la puerta a 90°
V6:Hola       texto para la LCD
V20:-40,85    joystick: izquierda y adelante

# placa → app
V10:24.1      temperatura
V7:DISPARO    alarma activada
V22:18        obstáculo a 18 cm

Código en la placa (ESP32)

#include "PanelLink.h"   // librería del proyecto

PanelLink panel("Casa Domotica");

void setup() {
  panel.beginWiFi("MiRed", "clave");
  panel.on(3, [](String v) {
    puerta.write(v.toInt());   // servo
  });
}

void loop() {
  panel.run();
  panel.send(10, leerTemperatura());
}
